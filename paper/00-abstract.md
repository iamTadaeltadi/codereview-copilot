# Can this benchmark measure context? Diagnostics for context-dependent code review

## Abstract

Systems that give a language model more of the repository during code review change which code the model sees and how its relationships are described. Before asking whether either helps, we ask whether a benchmark can measure the help at all, and answer with four diagnostics and a record. A partial-input ceiling: given only the diff, a model finds the mutated line in 93%, 97.8% and 95.5% of tasks on three successive versions of a generated cross-file benchmark, the last built after an external review had closed every known leak; the model flags most changed lines, so detection cannot separate one context condition from another. On 219 test-verified real defects the same check gives 33%, and that is the only set in this paper with headroom. An anchor-versus-evidence measurement on 291 real review comments: every one anchors on a changed file, yet 33 to 50% justify themselves with code the diff does not contain. A contrast set of safe twins, the same mutation placed where every caller in the repository tolerates it: under a prompt that presumes a defect no arm on two models leaves more than 11% of them unflagged; under a neutral prompt gpt-4o-mini leaves 82% alone from the diff, 54% when shown the caller that tolerates the change, 40% with a bare link stated between the snippets and 11% with the relation and its argument named, while foreign code of the same length changes nothing, so dependency metadata on a safe change drives false alarms in proportion to how much it says. On the stopped third-version run, showing the depended-on caller lowers precision by 14 points against the diff alone while foreign code of the same length does not, and stating the link between the snippets recovers none of it. A test-verification check: of 86 generated defects run against their repositories' own test suites, 17 are caught by an existing test. On the set with headroom, retrieval that reaches the depended-on caller through the dependency graph localises 48% against 33 to 36% for the diff alone and for random or lexical retrieval at the same budget. A held-constant-evidence experiment on dependency metadata was designed, pre-registered and run twice; both runs are withdrawn, the second after external review found five instrument defects, and the ceiling that survived their repair is why it is not run a third time. Everything, including the withdrawn runs, is released.
