# Can this benchmark measure context? Diagnostics for context-dependent code review

## Abstract

Systems that give a language model more of the repository during code review change two things at once: which code the model sees and how its relationships are described. We first ask whether a review benchmark can measure context at all, by applying three tests that are well known elsewhere and rarely run here. A partial-input baseline: a model given nothing but the diff finds the defect line in 97.8% of tasks on a mutation benchmark with verified cross-file evidence. An anchor-versus-evidence measurement on 291 test-verified real defects: every comment anchors inside the changed files, and 33 to 50% refer to code the diff does not contain. And a contrast set of matched safe twins: the same mutation placed where the shown caller is verifiably robust, so that only the other file separates defect from safe; no arm on either of two models clears more than about a fifth of them.

On the benchmark that admits it, we hold the evidence fixed and vary only the dependency metadata between snippets, across three model families and two serialisations, with a density-matched scrambled control, a foreign-repository control, a header-only control, a comprehension probe and two judges from different families. The real caller raises caller-grounded explanation by 8 to 13 points over foreign code at equal budget under the independent judge, while the header alone adds nothing. A bare true link raises that rate by 7 to 12 points on two families under one serialisation and not the other, and raises precision, which needs no judge, by 10 to 14 points on all four runs; a pre-registered keyword rubric, found invalid before the full data, spans zero and is reported as such. On 219 real defects, graph retrieval repaired to reach the caller localises 48% against 33 to 36% for the diff alone and for random, random-other-file or lexical retrieval at the same budget.

We release the generator, the twin benchmark, the frozen runs, both judges with their validation, the analysis, and the record of the claims withdrawn during this work.
